# Telegram-бот для заработка звёзд

Бот, где пользователи зарабатывают Telegram Stars за рефералов (3★) и задания
(0.5★), а выводят подарками (15–100★) через ручное подтверждение админом.

## Установка

```bash
py -m venv .venv
.venv\Scripts\activate        # Windows
py -m pip install -r requirements.txt
copy .env.example .env        # заполнить BOT_TOKEN, ADMIN_IDS, ADMIN_CHAT_ID
```

В `.env` обязательны только `BOT_TOKEN` и `ADMIN_CHAT_ID` (а также `ADMIN_IDS`
для доступа в `/admin`). Партнёрские ключи и публичный адрес API задаются в
админ-панели и хранятся в БД.

## Запуск

```bash
py run.py
```

Бот должен работать на публичном сервере (VPS/домен) — иначе партнёрские боты
не смогут отправлять подтверждения.

## База данных

По умолчанию используется SQLite по пути из `DB_PATH` (`data/bot.db`). Если у
хостинга нет постоянного диска, при переразвёртывании данные теряются. Чтобы
этого избежать, задайте переменную окружения `DATABASE_URL` с адресом внешней
PostgreSQL, например:

```
DATABASE_URL=postgresql://user:pass@host:5432/db?sslmode=require
```

Если `DATABASE_URL` не задана, бот работает на SQLite, как раньше.

## Тесты

```bash
py -m pytest -v
```

## Админ-панель (`/admin`)

- **🤝 Партнёры** — создать партнёра (генерируется API-ключ) и удалить.
- **⚙️ Настройки** — публичный адрес API (подставляется в готовый код).
- **Спонсоры** — ссылка → название, срок действия (часы, 0 = бессрочно),
  лимит прохождений (0 = без лимита); для ботов выбирается партнёр и сразу
  присылается готовый код.
- **Задания**, **Рассылка**, **Статистика**, **Заявки на вывод**.

## Партнёрская интеграция

Старт в чужом боте нельзя проверить через Telegram API, поэтому партнёрский бот
сам подтверждает действие запросом. При создании бот-задания/бот-спонсора бот
присылает готовый сниппет; ключ берётся из раздела «Партнёры».

```
POST /partner/confirm
{"api_key": "<ключ партнёра>", "user_id": 123, "task_id": 7}
# или
{"api_key": "<ключ партнёра>", "user_id": 123, "sponsor_id": 3}
```

Неверный ключ → 403; повторный запрос не начисляет повторно.

## Docker / хостинг

Сборка и запуск локально:

```bash
docker build -t stars-bot .
docker run -d --name stars-bot \
  -e BOT_TOKEN=123456:ABC... \
  -e ADMIN_IDS=123456789 \
  -e ADMIN_CHAT_ID=-1001234567890 \
  -v stars-data:/app/data \
  -p 8080:8080 \
  stars-bot
```

- Порт сервера берётся из `PORT` (даёт хостинг), иначе из `PARTNER_API_PORT`,
  иначе `8080`.
- БД хранится в `/app/data/bot.db` — подключите volume, чтобы не терялась.
- Секреты передаются переменными окружения, `.env` в образ не кладётся.
- Проверка живости: `GET /health` → `{"ok": true}`.
